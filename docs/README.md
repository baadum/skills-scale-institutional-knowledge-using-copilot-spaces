# OctoAcme Project Management Docs

This README indexes the OctoAcme project management process documents and provides a brief overview of the processes used across projects.

## Project management processes (brief)

OctoAcme follows an iterative, cross-functional delivery approach with clear ownership and regular communication. Work starts with project initiation, where a one-pager defines the problem, goal, stakeholders, timeline, and risks. Approved initiatives move into planning, where the team breaks work into shippable increments, prioritizes the backlog, sets a Definition of Done, and captures dependencies and risks. During execution and tracking, teams use a project board, keep pull requests small when possible, and rely on CI, testing, and review workflows to maintain progress and quality. Releases include pre-release checks, smoke testing, rollback planning, and stakeholder communication, while retrospectives turn learnings into action items for continuous improvement.
